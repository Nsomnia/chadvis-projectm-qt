## CI went dark: duplicate YAML keys (T0308, closed)
- `build.yml`, `tsan.yml`, `asan.yml` each ended up with **two `modules:` keys in one
  `with:` block** — a Qt step already requested `qtmultimedia` at the end of the block, and
  the Multimedia fix appended a second beside `target:`.
- GitHub rejects a repeated mapping key and refuses the file → runs came back `failure` with
  **zero jobs** and "This run likely failed because of a workflow file issue". `gh run rerun`
  refuses such a run. `yaml.safe_load` keeps the last duplicate and says nothing, which is
  why every local check was green.
- **Diagnosis trick worth keeping:** `gh workflow run <file> --ref main` returns
  `HTTP 422 ... failed to parse workflow: (Line: 153, Col: 11): 'modules' is already
  defined` — GitHub's own parser, for free, with the line number. That is the fastest way to
  validate a workflow without pushing.
- Added `scripts/check-workflows.py`: dependency-free indentation-aware scanner (repeated
  keys, tab indentation, missing `jobs:`), skips block scalars. Verified against a
  re-duplicated copy — names the same line GitHub did.

## Linux gate was red for a real reason (T0309 filed)
- `unit_tests` failed on both Ubuntu jobs (run 39395268941): six `FAIL!` in
  `TestBrowserCookieImport`. `deriveChromiumKey`/`decryptChromiumValue` are
  `#ifdef Q_OS_MACOS` and return `{}` elsewhere by design
  (`BrowserCookieImport.cpp:257`), and `candidateBrowserNames()` probes
  `~/Library/Application Support/` — so the fixture encrypted to nothing.
- Fixed with `REQUIRE_MACOS_SAFE_STORAGE()` (no-op on macOS, `QSKIP` elsewhere) on seven
  tests. macOS run: 18 passed / 0 failed; full `unit_tests` exit 0, zero `FAIL!`.
- Product question left open as T0309: the Import affordance is offered on Linux/Windows
  where it can only report "No Suno cookies were found".
