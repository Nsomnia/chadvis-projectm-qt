### Security
- **Mutation 401 replay disabled** *(2026-09-25)* — Authenticated request queue now carries an explicit replay policy; read-like calls may refresh once, while notification mark-all-read and audio-upload finalization fail terminally on 401 instead of replaying a mutation. Added a focused fake-reply regression.
- **Declaration-only Suno surface retired** *(2026-09-25)* — Removed 27 undefined capture-gated fetch methods and their unused signals from `SunoClient`; live captured Library/Explore/notification/account/upload methods remain unchanged.
- **Credential/request epoch fencing** *(2026-09-25)* — `SunoClient` now invalidates queued requests, retries, auth waiters, and tracked replies on sign-out, credential replacement, and auth loss; stale restore callbacks publish only terminal readiness. Direct audio uploads cancel on credential invalidation. Pending Library/Explore readiness wakes correctly, and `NeedsReauth` requests wait for an in-flight bearer refresh.
- **Undocumented Browser-Token removed** *(2026-09-25)* — Studio request headers no longer synthesize a timestamp-based Browser-Token from an explicitly undocumented recipe. Requests remain fail-closed until a route-specific header is backed by a fresh direct capture; existing Authorization/Device-Id/Origin/Referer policies are unchanged.
- **Canonical Clerk session selection** *(2026-09-25)* — Bearer recovery now requires a non-empty `last_active_session_id` and an exact matching `sessions[].id`; first-array fallback, missing-ID matching, and direct response-token fallback are rejected. Automatic `/tokens` fallback after client/touch failure is removed until route preference is capture-backed. `ClerkClientInfo::preferredSession()` follows the same fail-closed rule.
- **Captured media transport lockdown** *(2026-09-25)* — MP3 playback now accepts only HTTPS media-array URLs on the exact captured `audiopipe.suno.ai` origin with default/443, non-empty paths, and no userinfo/fragments. Legacy `audio_url`, image-host media, suffixes, cleartext, and forbidden sentinels are rejected. Download retries discard partials and restart from byte zero; redirect following is manual and 3xx replies are terminal.
- **Settings credential ownership and live clear** *(2026-09-25)* — `SettingsBridge` no longer performs synchronous keychain reads/writes. It debounces manual edits and delegates persistence plus activation to `SunoClient`, caches the configured credential from client state, prevents stale restore results from overwriting pending edits, and routes explicit clearing through `clearLocalCredentials()` so durable and in-memory sign-out cannot diverge. Added an injected-backend regression for active bearer state and clearing.
- **Remote artwork origin lock** *(2026-09-25)* — Feed/Explore image values are now sanitized at both clip parsing and QML bridge exposure. Only HTTPS URLs on the exact captured `cdn1.suno.ai` and `cdn2.suno.ai` hosts, with default/443, no userinfo/fragment, and a non-empty path, can reach `Image`; the unused raw `audio_url` bridge field was removed.
- **Audio upload origin lock** *(2026-09-25)* — The direct multipart leg now rejects initializer URLs unless they use HTTPS on the exact capture-proven `suno-uploads.s3.amazonaws.com` host, default/explicit port 443, a non-empty path, and no userinfo or fragment. Manual redirect handling and the no-Suno-bearer rule remain intact; policy coverage includes alternate hosts, suffix confusion, cleartext, userinfo, nondefault ports, fragments, relative URLs, and local schemes.
- **JWT scrubbing from git history** *(2026-09-21)* — 1,215 Clerk handshake JWTs and 2 GitHub CDN JWTs were discovered in committed log files (`docs/suno_api/raw/`). All were expired (April 2026) and single-purpose, but `git filter-branch --tree-filter` rewrote the full history to replace them with `[REDACTED-JWT]`. Backup refs deleted, reflog expired, garbage collected. Working tree is clean — nothing pushed to remote.
- **SQL injection fixed in search_db.sh** *(2026-09-21)* — User input was concatenated directly into SQLite queries. Replaced with `.param` bound parameters plus single-quote escaping. Hardcoded `/home/nsomnia/` path replaced with XDG-aware `${XDG_DATA_HOME:-$HOME/.local/share}`.

### Fixed
- **Actionable persistence errors** *(2026-09-25)* — Preset scanning/state, playlist persistence, FBO resize, Suno database writes, and theme/config saves now log `Result` failures instead of silently discarding them.
- **Application shutdown ordering** *(2026-09-25)* — Explicitly destroy QML/engine and dependent controller, lyrics, preset, recorder, audio, and Qt application lifetimes in dependency order.
- **Audio callback allocation safety** *(2026-09-25)* — `AudioEngine` preallocates its PCM scratch during `init()` and drops oversized callback buffers rather than resizing from the audio callback.
- **Cached QML singleton lifetime** *(2026-09-25)* — `QmlSingletonBridge` now clears its cached instance pointer during base destruction, covering parented and unparented bridge singletons across engine teardown/restart; a regression verifies the pointer is null after destruction.
- **End-to-end captured aligned lyrics in Listen and Video** *(2026-09-25)* — Download & Play now emits the authoritative clip ID only after the local file is current. `SunoController` maps captured `aligned_words` against feed `metadata.lyrics`, publishes cache/DB/request results only for the active clip, and drives the existing `LyricsSync`/`LyricsBridge` path. Late responses now start synchronization while audio is already playing, track clears are synchronous, one timer owns position updates, invalid payloads become terminal, and lazy bridge construction connects correctly. Added eight focused pipeline tests.
- **AudioAnalyzer/PFFFT thread safety** *(2026-09-25)* — Replaced shared mutable FFT work/output arrays with 16-byte-aligned per-call scratch, kept the thread-safe immutable PFFFT setup behind an RAII owner, serialized analyze/reset/PCM state, and made setup failure return deterministic zero magnitudes. Pinned the verified PFFFT revision instead of tracking `master`. Added tone/reset, concurrent independent-analyzer, same-instance reset/analyze/copy, invalid-input, and ThreadSanitizer coverage.
- **Library/Explore self-rejected asynchronous credential restore** *(2026-09-25)* — Coalesced secret-store reads now retain and notify every completion, including discarded startup reads, instead of silently dropping reload intent. Library and Explore hold their loading state until the shared restore resolves and only then classify authentication, eliminating the deterministic startup refresh failure where an in-flight keychain read was treated as signed out. Added injected-worker regression coverage for in-flight and subsequent refreshes.
- **App never opened its window (QML import)** *(2026-09-24)* — `AccountPage.qml` used `import "./AccountSessionCard.qml" as …`, which is not a valid QML import form. The engine reported "no such directory" and the failure chained upward: `AccountPage unavailable` → `SettingsWindow unavailable` → `Failed to create QML window`. Same-directory QML types resolve implicitly, so the import was removed. The app now creates its window.
- **Startup hang on the keychain** *(2026-09-24)* — a `sample` stack on a hung run proved a credential read was running on the GUI thread inside `SunoClient`'s constructor (before the QML engine existed) and blocking in `SecItemCopyMatching → CSSM_DecryptDataFinal → mach_msg` on `securityd`. Interactive runs recovered in ~10 s when a keychain dialog was answered; unattended runs waited forever. Keychain I/O now runs on an owned worker thread with a queued hop back to the GUI thread, requests coalesce, `reloadStoredCredentials()` is no longer a blocking GUI-thread read, and macOS uses the modern data-protection keychain instead of the legacy CSSM path. Startup went from a multi-second hang (or indefinite) to ~2 s end to end.
- **Session refresh could never succeed** *(2026-09-24)* — the captured successful Clerk `touch` reply carries the JWT at `$.response.last_active_token.jwt` / `$.client.sessions[].last_active_token.jwt` and has no `$.response.sessions` at all, but the parser only read `$.response.sessions[*]`. Every refresh was reported as "no usable sessions" and flipped the app to `NeedsReauth`, so a live session could never survive. The parser now accepts every capture-proven location, and failures are classified (`no active session` / `credential rejected` / `unexpected response shape` / expired / undecodable) instead of always being reported as "session expired".
- **Clips never rendered; spinner only cleared via watchdog** *(2026-09-24)* — `Application::init` calls `SunoBridge::setSunoController()` before the engine loads, and because the bridge is a lazy singleton created on first QML access, every controller signal connection was silently skipped. The wiring is now order-independent and idempotent.
- **Window failed to load (main.qml onViewChanged)** *(2026-08-27)* — `property string activeView` handler was `onViewChanged` (non-existent). Fixed to `onActiveViewChanged`; `QQmlApplicationEngine failed to load component` cleared, window now creates (`qmllint` clean).
- **Library spinner + one-page stall** *(2026-08-27)* — `loading` only cleared in `onLibraryUpdated` so auth/401/network failures left infinite spinner; pagination required manual scroll but a tall window never reached `atYEnd`. Fixed via uniform failure clearing + full auto-pagination loop + viewport-fill guard (see Added above).
- **Broken HEAD** *(2026-08-25)* — Removed dangling `SunoPersistentAuth` references left by an earlier deletion (CMake + `SunoAuthManager`); persisted-session restore now reads CONFIG directly.
- **Silent recordings** *(2026-08-25)* — Root cause of "audio never encoded during recording": `VideoRecorder::setAudioQueue` was never wired. Wired in `Application::init()` along with the visualizer renderer's PCM queue.
- **Record button highlight inverted**, **config defaults drift** (parser fallbacks now derive from struct initializers), **Suno download/debug settings reset every launch** (now persisted), **non-idempotent Suno DB migration** (gated behind `PRAGMA user_version`).
